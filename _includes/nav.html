{# nav.html — the top bar. ONE template for every neohiro-network Jekyll site. CONTRACT — keep in sync across neohiro / frenzypenguin-media / openstageisland / transhumanists (SSOT: template-shared/_includes/nav.html): 1. LABELS ARE ONE WORD. The bar is not sticky, so a wrapping row would shift layout and a long label is the only thing that can force a wrap on a 360px phone. If you need two words, the item belongs in the Community menu. 2. ORDER IS FIXED: [section links] [Community ▾] [Login] [♥ Sponsor] [GitHub glyph] The GitHub glyph is always LAST so it sits hard against the right edge. 3. `[data-nav-auth]` IS RENDERED HERE, NOT INJECTED BY JS. network-ux.js `injectNavAuth()` bails out when it sees that attribute and then only toggles .hidden / fills avatar+name+role. Static markup means no post-load reflow and no duplicate buttons. 4. THERE IS NO CONTACT ITEM. AI and Contact are one surface — the assistant dock at the bottom of every page. Login lives here, in the top bar. 5. Links come from `_config.yml` so each site gets its own set from the same template. Format is a YAML list of pipe-separated strings, because URLs contain colons and `:` is therefore not a safe delimiter here: nav_links: - "Tools|/#featured-tools" - "Beats|/heartbeats/|4" # trailing field = drop priority community_links: - "Discussions|https://github.com/neohiro/windows/discussions" `opt` (2|3|4) marks drop-order for narrow screens, dropped highest-first: 4 → ≤1180px, 3 → ≤1000px, 2 → ≤820px Everything dropped is still reachable from the footer + Community menu. 6. THE HEADER SCROLLS AWAY. Below the fold it translates out of view and a compact brand pill takes its place, so the hero and the live signal get the full viewport. #} {%- assign gh = site.github_username | default: 'neohiro' -%} {%- assign links = site.nav_links -%} {%- if links == nil or links == empty -%} {%- comment -%} Safe default for a site that has not configured nav_links yet. {%- endcomment -%} {%- assign links = "Home|/|, Repos|/repositories/|, Media|/media/" | split: ", " -%} {%- endif -%}
