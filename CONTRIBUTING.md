# Contributing to transhumanists

Thank you for contributing to the transhumanists knowledge hub!

## How to contribute

### Reporting issues
Use the **Bug report** issue template for:
- Broken links or formatting errors
- Incorrect or outdated information
- Missing content

### Proposing research topics
Use the **Research request** issue template to propose new content areas.
We cover: longevity, cognitive enhancement, neural interfaces, biohacking,
AI-human integration, and the ethics of human enhancement.

### Editing content
This is a Jekyll GitHub Pages site. To update content:

1. Fork this repository
2. Edit the relevant `.md` file in the root directory
3. Submit a pull request

## Standards

- Claims should be backed by peer-reviewed sources or reputable publications.
- Controversial claims should acknowledge uncertainty and competing viewpoints.
- No medical advice — this site documents research, it does not give medical recommendations.

## Code of conduct

All contributors are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
